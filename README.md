# Liq Budz

Premium East African spirits, Ugandan canned beers, banana wines, and party packs for the diaspora across Germany and Europe.

## Preview

GitHub Pages is configured to publish the storefront automatically from the `arena/01a08809-liqbuddies` branch.

Preview URL: <https://mikeo-ne.github.io/liqbuddies/>

If the URL is not active yet, open the repository **Settings → Pages**, choose **GitHub Actions** as the source, then re-run the **Deploy Liq Budz preview** workflow from the Actions tab. Every push to the session branch will redeploy the latest storefront.

## Local preview

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open <http://localhost:4173>.
